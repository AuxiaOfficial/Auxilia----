## 8.3 热力图（FR-G2）

`src/components/achievement/Heatmap.tsx`，**纯 SVG，不引库**。

- 规格：格子 12×12px，间距 3px，圆角 2px
- 布局：横向按周（列），纵向按星期（行，周一在上）
- 范围：`近 12 周`（默认）/ `今年` 两档，右上角切换
- 颜色阶梯（用 `--accent` 白，靠透明度区分）：
  ```
  0min      rgba(255,255,255,0.04)
  <30min    rgba(255,255,255,0.14)
  <60min    rgba(255,255,255,0.30)
  <120min   rgba(255,255,255,0.50)
  <180min   rgba(255,255,255,0.70)
  ≥180min   rgba(255,255,255,0.92)
  ```
- 左侧显示 `一 / 三 / 五` 三个标签（11px，`--text-3`）
- hover 单格：格子轻微放大 1.15 并出现 tooltip `10月23日 · 2 小时 15 分`
- 数据来源：SQL 一次聚合
  ```sql
  SELECT date(started_at/1000, 'unixepoch', 'localtime') AS d,
         SUM(active_seconds) AS s
  FROM task_runs WHERE ended_at IS NOT NULL GROUP BY d
  ```

## 8.4 图表（FR-G3）

### 柱形图（每日专注）
- 7 天（默认）/ 30 天切换
- 柱宽自适应，间距 6px，圆角顶部 2px
- 柱子用 `--accent` 60%；今天那根用 100% 并在顶部加一个 3px 亮点
- 底部标签：周一~周日，`--text-3` 11px
- 无 Y 轴刻度线（不要网格背景）。最高值那根柱顶部标一个数字

### 环形图（时间去向）
- 取 Top 5 任务 + 「其他」
- 圆环直径 120px，线宽 10px，`stroke-linecap: round`
- 各段颜色：全部用白色不同透明度（0.9 / 0.68 / 0.48 / 0.32 / 0.20 / 0.10），**不要上彩色**
- 圆心显示总时长（24px / 500）
- 右侧图例：色块 + 任务名 + 百分比，最多 6 行

### 交互
- hover 某段/某柱时，其余元素降到 0.3 透明度（用 CSS 类控制，不用重算 path）
- 点击柱子 → 展开当日任务明细（行内展开，不是弹窗）

### 视觉
- 已解锁：40×40 的圆角方形（`--r-md`），`--surface-2` 底，中间是 lucide 图标（20px）。tier 用图标颜色区分：bronze `#C08A5E`、silver `#B8BFC7`、gold `#E0B45C`（**这是全局唯一的彩色使用场景，仅限徽章图标**）
- 未解锁：同尺寸，图标 `--text-3` 且 `opacity 0.25`，整体 `filter: grayscale(1)`，hover 显示条件
- 点亮时（首次获得）：从 0.8 放大到 1.08 再回 1，配合一圈极淡的 ring 扩散（400ms）
- hover：轻微上浮 2px + tooltip（名称 / 条件 / 获得日期 / `兑换 +30 coin` 按钮）

### 兑换（FR-G6）
- 未兑换的徽章右上角有一个 4px 的小圆点
- 点击「兑换」→ coin 入账，圆点消失，徽章 `redeemed=1`
- 已兑换的徽章仍显示，只是没有兑换入口（不要藏起来，那是用户的历史）

## 8.6 coin 结算（FR-G4）

- 完成任务：`coin = floor(active_seconds / 60) * 2`（每分钟 2 coin）
- 中止：0
- 徽章兑换：按定义
- 余额显示在成就页顶部，和主界面左栏底部
- 余额变化时数字有一次滚动动效

## 8.7 装饰墙（FR-G7）

从成就页右上角「装饰墙」进入（`view = 'wall'`）。

- 画布：中栏全宽，高度撑满，背景纯黑，**加一层极淡的点阵网格**（`radial-gradient` 每 24px 一个 1px 点，透明度 0.03）
- 可放置三类物品：
  - `decoration`：已购装饰品
  - `badge`：已获得徽章
  - `task`：`level >= 5` 的任务卡片
- 拖拽：从下方「物品抽屉」拖到画布上，用 Pointer Events（复用 P5 的拖拽骨架，但落位吸附到 8px 网格）
- 已放置的物品可再拖动、可右键（自绘菜单）删除、可缩放（拖右下角手柄，范围 0.6~1.6）
- 位置存 `wall_items`（`x/y` 为相对画布百分比，避免窗口尺寸变化错位）
- 抽屉在画布底部，横向滚动，每项 64×64
- **不要做**物理引擎、不要做碰撞、不要做旋转

## 关键要求

1. **所有图表手写 SVG**。引入任何图表库直接判定不通过。
2. 热力图 365 格必须一次性渲染完成，用 `<rect>`，不要用 div（性能差 5 倍以上）。
3. 统计全部由 Rust/SQL 聚合后返回小结果集，前端不做大数据遍历。
4. 装饰墙的坐标存百分比，不存像素。
5. 徽章的 tier 是全局唯一允许出现彩色的地方，其他所有地方保持灰阶。
6. 成就页在数据为空（新用户）时必须有合理的空状态，不能是一片空白或 NaN。

## 验收标准

| # | 检查项 |
|---|---|
| 1 | 造 30 天假数据后，热力图颜色分档正确（手算对比 3 个格子） |
| 2 | 热力图 365 格渲染耗时 < 50ms（Performance 面板） |
| 3 | 柱形图 7 天/30 天切换正常，today 那根高亮 |
| 4 | 环形图百分比合计 100%，Top5+其他 逻辑正确 |
| 5 | 首页无数据时成就页显示空状态，无 NaN / Infinity |
| 6 | 首次完成任务后，`first_task` 徽章弹出且有解锁动效 |
| 7 | 徽章兑换后 coin 增加，重启后仍是已兑换状态 |
| 8 | 同一徽章不能重复兑换 |
| 9 | 连续 7 天后 `streak_7` 正确解锁（用改系统日期验证） |
| 10 | 装饰墙可拖入装饰品，位置重启后保持 |
| 11 | 装饰墙在窗口缩放后物品位置不错乱（百分比存储生效） |
| 12 | 商店购买扣费正确，余额不足时无法购买 |
| 13 | 全局搜索：除徽章 tier 外无其他彩色色值 |
| 14 | 成就页滚动流畅，无掉帧（Performance 面板） |
