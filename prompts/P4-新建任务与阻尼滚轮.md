## 目标

新建任务面板能用，**阻尼滚轮的手感达到"想反复滚着玩"的程度**。

这一期是整个产品体验的分水岭。滚轮做糙了，软件立刻从"精致"掉到"能用的网页"。

## 任务

### 4.1 浮层结构

新建面板是**居中浮层**，不是新页面、不是侧滑抽屉。

```
背景遮罩：rgba(0,0,0,0.6) + backdrop-filter: blur(8px)
面板：   520px 宽，--surface-1，--r-lg，无边框，无阴影
        进场：opacity 0→1 + scale 0.97→1 + translateY 8px→0，--dur-base
        Esc 关闭（有内容时二次确认）
```

### 4.2 五组属性的排列

**不要做成 `<label> + <input>` 的表单。** 做成"一问一答"的纵向流：

```
╭─────────────────────────────────────────╮
│  要做什么？                              │   ← 标题输入，24px，无边框
│  ─────────────────────────────────────  │      占位符就是这句话
│                                         │
│  持续性        总是存在 · 完成即删 · 到期删 │   ← 分段选择器
│  持续时间      倒计时 · 正计时 · 定时触发   │
│  时长          [ 小时轮 | 分钟轮 ]        │   ← 仅倒计时/正计时显示
│                [25分] [45分] [1时] [1.5时] │
│  提示          弹窗 · 闪屏 · 铃声          │   ← 三个独立开关
│  显示          顶栏 · 不显示 · 浮窗        │
│                                         │
│                          [ 创建 ]        │
╰─────────────────────────────────────────╯
```

规则：
- 左侧 label 固定 13px `--text-3`，宽度 72px，右对齐
- 右侧选项为**文字胶囊**：未选 `--text-2` + 透明底；选中 `--text-1` + `rgba(255,255,255,0.10)` 底 + `--r-full`
- 组与组之间间距 20px，组内胶囊间距 8px
- **条件显隐用高度动画**：选「定时触发」时，滚轮区域收起、日期选择器展开（`--dur-base`），不是直接消失
- 标题为空时「创建」按钮 `opacity: 0.3` 且不可点

### 4.3 双轮阻尼滚轮 ★核心

`src/components/creation/WheelPicker.tsx` + `src/lib/physics.ts`

#### 结构
```
┌────────────────────┐
│   12               │  ← 上方项，scale 0.82，opacity 0.25
│  ▔▔▔▔▔▔▔▔▔▔▔▔▔    │  ← 选中区上边线 rgba(255,255,255,0.10)
│      01            │  ← 中心项，15px / 500 / #FAFAFA
│  ▁▁▁▁▁▁▁▁▁▁▁▁▁    │  ← 选中区下边线
│   02               │
│   03               │
└────────────────────┘
   小时        分钟
```
- 单轮尺寸：宽 64px，高 160px，每项 44px
- 两轮间距 8px，中间一个冒号 `:`（`--text-3`，20px）
- 上下用 `mask-image: linear-gradient(transparent, #000 28%, #000 72%, transparent)` 做渐隐
- 选中区两条线用伪元素绝对定位，`pointer-events: none`

#### 物理（严格照 `docs/02-技术架构.md` 6.2 实现）

```ts
const WHEEL = {
  ITEM_H: 44,
  FRICTION: 0.94,     // 自由滑行衰减（越小停得越快）
  SPRING_K: 0.16,     // 吸附刚度
  SPRING_D: 0.70,     // 吸附阻尼
  MIN_VEL: 0.4,
  WHEEL_GAIN: 0.32,
};
```

实现要点（缺一条手感就不对）：
1. 用单一 `requestAnimationFrame` 循环驱动，**不要每个 setState 触发重排**
2. 位移写进 `element.style.transform`，绕过 React 渲染（render 只更新最终数值）
3. `wheel` 事件 `{ passive: false }` + `preventDefault()`，防止页面跟着滚
4. 自由滑行阶段按 `FRICTION` 衰减；速度低于 `MIN_VEL` 才进入吸附阶段
5. 吸附阶段用弹簧方程 `v += (target - offset) * K; v *= D`，**不是直接 tween 到目标**
6. 收敛判定：`|target - offset| < 0.3 && |v| < 0.3` 才 `snap` 并停止 rAF
7. 循环取值：小时 `((i % 24) + 24) % 24`，分钟同理；`offset` 本身连续不跳变
8. 支持鼠标按住拖动：`pointerdown` 记录起点，`pointermove` 直接设 `offset`，同时根据位移差算 `velocity` 用于松手后滑行

#### 视觉映射（每项）

```js
const d = offset - index * ITEM_H;
const nd = Math.min(Math.abs(d) / (ITEM_H * 3), 1);
style.transform = `translateY(${d}px) scale(${1 - nd * 0.18})`;
style.opacity = 1 - nd * 0.75;
```

#### 数值同步
- 滚动中实时更新值（不要等停下），但**外部输入框不显示**，避免视觉噪音
- 下方显示一行大号当前值 `01:30:00`，36px / 300 字重 / `--text-2`（这是滚轮的"回声"，让人知道现在是多少）

### 4.4 快捷胶囊（FR-C4）

滚轮下方一行 5 个胶囊：`25分` `45分` `1小时` `1.5小时` `2小时`

点击行为（**关键：不能瞬移**）：
```ts
// 不是直接 offset = target
state.target = value * 60 * ITEM_H_minute;   // 分钟轮的目标像素
state.velocity = (state.target - state.offset) * 0.10;  // 给一脚初速度
// 之后交给同一个 rAF 循环，用弹簧滚过去
```
效果：明显看得出轮子在"滚"过去，时长 ≈ 300-450ms，有减速感。

点击后胶囊自身有一个极轻的按下反馈（`scale 0.96 → 1`，`--dur-fast`）。

### 4.5 提示力度（FR-C6）

三个独立开关，横向排列，每个是「图标 + 文字 + 开关点」：

```
◱ 弹窗     ◇ 闪屏     ♪ 铃声
```
- 开关是 32×18px 的胶囊，关闭 `rgba(255,255,255,0.10)`，开启 `--accent`，圆点白色 14px
- 切换动效 `--dur-fast`，圆点用 `transform: translateX`
- 默认：弹窗开，闪屏关，铃声关
- **勾选「闪屏」时旁边出一行 11px 灰字**：「全屏会闪一下白色，约 0.13 秒」——这个功能需要解释，否则用户会以为中了病毒

### 4.6 显示方式（FR-C7）

三个胶囊单选，选中项下方出 11px 灰字说明：
- 顶栏：会在屏幕顶部常驻一条小字
- 不显示：只在软件内可见
- 浮窗：一个可拖动的小卡片悬浮在桌面上

### 4.7 保存与成功态（FR-C8）

点「创建」→
1. 调 `taskRepo.create()`，成功后关闭浮层
2. 中栏短暂显示成功态（1.2s）：一个极简的对勾 + 任务名 + 两个按钮
   ```
            ✓
        已创建「写方案」
      [ 马上开始 ]   [ 暂不开始 ]
   ```
3. 「马上开始」→ 进入 P6 的开始流程（本期先跳到 focus 视图占位）
4. 「暂不开始」→ 回 home，左栏新任务有一次高亮脉冲（背景闪一下 `--surface-3`，400ms）

**不许**用 toast 通知，不许弹系统通知。

## 关键要求

1. **手感优先于代码整洁。** 如果两者冲突，先保证手感，代码可读性次之（但仍不许留 dead code）。
2. rAF 循环必须在组件卸载时 `cancelAnimationFrame`，否则会内存泄漏并导致后续组件动画错乱。
3. 滚轮区域禁止选中文本：`user-select: none`。
4. 滚轮必须支持键盘：`↑↓` 调 1 格，`PgUp/PgDn` 调 5 格，`Home/End` 到边界。
5. 所有过渡 curve 用 `--ease-out`，不要用 `ease` 默认值。
6. 时间上限 `23:59`，下限 `00:01`（0 分钟没有意义）。

## 禁止

- ❌ 用 CSS `scroll-snap` 实现滚轮（太硬，没有惯性，手感直接废）
- ❌ 用 `setState` 驱动每帧动画（会掉帧）
- ❌ 用 `<input type="range">` 或 `<input type="time">`
- ❌ 引入第三方滚轮库
- ❌ 快捷胶囊直接 `offset = target`（瞬移，破坏手感）
- ❌ 用 toast 做创建成功提示
- ❌ 在浮层里加"帮助说明""小提示"段落
