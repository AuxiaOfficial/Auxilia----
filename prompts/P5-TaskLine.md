# P5 · TaskLine

**角色**：前端工程师（R3）
**前置**：P4 通过验收
**验收官**：R5

---

## 目标

右栏变成一个真正能用的时间看板：拖任务进去、按小时分组显示、多个 TL 切换、点击就开跑。

**这一期的核心不是拖拽技术，是让用户相信"它真的不会管我"。**

---

## 任务

### 5.1 数据与视图的对应关系

TL 是**可复用的参考看板**，不绑定具体日期。数据库 `taskline_entries` 用 `minute_of_day`（0-1439）定位。

- 落位吸附粒度：**15 分钟**
- 视觉组织：**按小时分组**（不是甘特条）

```
06:00 ────────────────────────────────
       ┌──────────────────────────┐
       │ 写方案              25m  │
       └──────────────────────────┘
07:00 ────────────────────────────────
       （空行，拖拽时才出现虚线框）
08:00 ────────────────────────────────
       ┌──────────────────────────┐
       │ 晨会                30m  │
       └──────────────────────────┘
       ┌──────────────────────────┐
       │ 回邮件              15m  │
       └──────────────────────────┘
```

### 5.2 时间轴

- 范围 `start_hour` ~ `end_hour`（默认 6~24），每小时一行
- 小时线：`1px rgba(255,255,255,0.04)`，左侧标签 11px `--text-3`
- 每个小时格子最小高度 64px，有任务时按内容撑高
- 初始滚动位置：当前时间上方 100px；如果当前时间不在范围内，滚到顶部
- 当前时间指示线：`--accent` 20%，左侧一个小圆点，每 60 秒重定位

### 5.3 拖拽入列（核心交互）

**用 Pointer Events 自定义实现，不用 HTML5 DnD**（HTML5 DnD 的拖影不可控，且无法做吸附预览）。

流程：
1. 在左栏任务项上 `pointerdown` → 记录起点，`pointermove` 超过 4px 才判定为拖拽（避免误触发点击）
2. 拖拽中：原任务项 `opacity: 0.4`，鼠标处跟一个**幽灵卡片**（`position: fixed`，`pointer-events: none`，只显示标题，宽度 240px）
3. 拖到右栏时间轴区域时：
   - 计算落点：`minute = clamp(round(((y - gridTop) / pxPerHour) * 60 / 15) * 15, 0, 1439)`
   - 目标小时行背景变 `rgba(255,255,255,0.03)`，行内出现一个 56px 高的虚线占位框
   - 幽灵卡片吸附到占位框位置（有 60ms 过渡，不要硬跟手）
4. `pointerup` 在有效区域 → 写入 `taskline_entries`，占位框淡出、真实卡片淡入（`--dur-base`）
5. `pointerup` 在无效区域 → 幽灵卡片飞回原位（`--dur-base`），无数据写入

细节：
- 判定「有效区域」是时间轴的 bounding rect 内
- 拖拽时整个窗口 `cursor: grabbing`
- 拖拽期间禁用文本选择：`document.body.style.userSelect = 'none'`，结束后恢复
- 同一任务可以拖进多个小时（允许，因为它是参考）

### 5.4 卡片

```
┌─────────────────────────────────────┐
│ 写方案                        25m  │   56px 高，--surface-1，--r-md
└─────────────────────────────────────┘
       ↑ hover 时右侧浮现 ⋯ 菜单
```
- 标题 14px `--text-1`，单行省略
- 右侧时长 11px `--text-3`（来自 `planned_seconds`，正计时任务显示 `∞`）
- hover：背景 `--surface-2`，右侧出现 `⋯`（16px，`--text-3`）
- `⋯` 菜单（浮层，不用系统菜单）：`开始任务` / `移到其他小时` / `从 TL 移除` / `删除任务`
  - 「从 TL 移除」只删 entry，不动任务
  - 「删除任务」需要二次确认
- **区块内拖动改时间**：按住卡片拖动，复用 5.3 的落位逻辑，实时显示目标位置
- 卡片左侧有 3px 竖条，颜色随任务等级变化（`rgba(255,255,255,0.06 → 0.22)`）

### 5.5 点击即开始（FR-D5，产品灵魂）

点击卡片本体（非 `⋯`）→ 立即进入开始流程。

- 本期 P6 未完成，先跳转 `view = 'focus'` 并显示一行提示"（P6 将在这里启动任务）"
- **绝对不许**做任何"到点自动开始""提醒该做下一件事"的逻辑。这是红线。

### 5.6 多 TL 与 CRUD

顶部工具条：
```
[ 周末 TL  ▾ ]                    [+]  [⋯]
```
- 点击名称展开下拉：列出所有 TL，底部「新建 TaskLine」
- 新建：行内输入框（不要弹窗），回车确认，Esc 取消，默认名「未命名 TL」
- `⋯` 菜单：`重命名` / `清空本 TL` / `删除本 TL`（二次确认）
- TL 切换时整个时间轴做 120ms 淡入淡出，滚动位置重置
- 选中的 TL 存 `settings` 表，下次启动恢复

### 5.7 空状态

时间轴内无任何条目时，中央显示：
```
把任务拖到这里
它只是个参考，不会自己跑
```
上面一行 15px `--text-3`，下面 11px `--text-3`（opacity 0.6）。

有内容后这段静默消失，不再出现。

## 关键要求

1. **拖拽必须支持从「任务池」和「另一个小时」两个来源**，共用同一套落位计算。
2. 落位计算必须处理滚动偏移（时间轴可滚动，`y` 要用相对滚动容器的坐标）。
3. 所有写库操作乐观更新：先改本地 state 再写库，失败回滚并提示。
4. 拖拽期间不得触发 `scroll`（时间轴不能自己乱滚），但**允许**拖到边缘时缓慢自动滚动（边缘 40px 内，速度 6px/帧）。
5. 一个小时内超过 4 个任务时，格子自然撑高，不出现内部滚动条。
6. 卡片菜单浮层要能超出右栏边界显示（用 Portal 挂到 body，或 `overflow: visible` 到容器外——按实际情况选，注意别被裁切）。

## 验收标准

| # | 检查项 | 判定 |
|---|---|---|
| 1 | 从左栏拖任务到 8:00 附近放下，条目落在 8:00-8:15 之间 | 查库看 `minute_of_day` |
| 2 | 落位吸附到 15 分钟整，无 8:07 这类值 | 查库 |
| 3 | 拖拽时原有任务项变半透明，有幽灵卡片跟随 | 目测 |
| 4 | 拖到有效区域出现虚线占位框，位置跟手 | 目测 |
| 5 | 拖到无效区域松手，卡片飞回，库中无记录 | 手动 + 查库 |
| 6 | 拖出去再拖回来，状态正确复位 | 手动 |
| 7 | 卡片拖动到另一小时，位置更新，不产生重复条目 | 查库 |
| 8 | 点卡片本体 → 进入 focus 视图（不自动计时） | 手动 |
| 9 | 点 `⋯` → 菜单出现，四个动作都正确 | 逐个测 |
| 10 | 「从 TL 移除」后任务仍在左栏任务池 | 手动 |
| 11 | 新建 TL → 空时间轴 → 切换回来数据还在 | 手动 |
| 12 | 删除 TL 后其条目一并删除，任务本体不受影响 | 查库 |
| 13 | TL 选择重启后保持 | 重启 |
| 14 | 当前时间线位置正确，1 分钟后自动移动 | 对比系统时间 |
| 15 | 空状态文案出现/消失时机正确 | 手动 |
| 16 | 时间轴滚动时拖拽落位仍然准确（滚到底部再拖） | 手动 |
| 17 | 拖拽全程无文本被选中 | 手动 |
| 18 | 代码中不存在任何自动开始任务的逻辑 | 全局搜 `autoStart` / `setTimeout.*start` |

## 禁止

- ❌ 用 HTML5 `draggable` / `dragstart` / `drop`（拖影不可控）
- ❌ 引入 `dnd-kit` / `react-beautiful-dnd` 等拖拽库（本项目拖拽场景简单，自己写更可控且省依赖）
- ❌ 做「到点自动执行」「下一项提醒」任何形式的自动推进
- ❌ 把 TL 和具体日期绑定
- ❌ 甘特图式的按分钟精确定位（本项目是看板不是甘特图）
- ❌ 用系统右键菜单

---

## 交付格式

同 P1，额外附 **一段 15 秒录屏**：拖入 → 落位 → 拖到另一小时 → 点击开始。
