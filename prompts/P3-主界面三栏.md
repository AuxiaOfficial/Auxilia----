## 任务

### 3.1 视图状态机（不起用路由）

在 `uiStore` 里用一个 `view` 字段驱动中栏：

```ts
type View = 'home' | 'focus' | 'finish' | 'achievements' | 'review';
```
- 切换用 Motion 的 `AnimatePresence`，`--dur-slow` + `--ease-out`
- 进入 `focus` 时，左右两栏**淡出并向两侧微移 8px**（不是滑动整页），中栏独占
- 返回 `home` 时反向
- **不要用 react-router**。窗口只有一个，页面切换是状态不是导航，用路由会带来 history 和卸载时机的一堆麻烦。

### 3.2 布局

```
┌──────────────────────────────────────────────────────────┐
│ TitleBar (38px, drag-region)                             │
├──────────┬────────────────────────────┬──────────────────┤
│ Sidebar  │      CenterStage           │  TimelinePanel   │
│ 260px    │      flex, max-w 720       │  380px           │
│          │                            │                  │
│ 搜索      │    ┌────────────────┐      │  ┌────────────┐  │
│ 任务列表  │    │  slogan 32px   │      │  │ TL 切换     │  │
│          │    │  副标题 13px    │      │  ├────────────┤  │
│          │    ├────────────────┤      │  │            │  │
│          │    │ 四个入口        │      │  │  时间轴     │  │
│          │    └────────────────┘      │  │  (P5 实现)  │  │
└──────────┴────────────────────────────┴──────────────────┘
```

细节：
- 三栏之间**不加分隔线**，靠 `--surface-1` 的极淡背景差异 + 间距区分。左右两栏背景 `rgba(255,255,255,0.02)`，中栏纯黑。
- 中栏内容垂直居中偏上（`padding-top: 18vh`），不是正中。
- 中栏最大宽度 720px 并水平居中，宽屏时不要把内容拉满。

### 3.3 Slogan 区

- 主标题 32px / 字重 500 / `--text-1` / 行高 1.3
- 副标题 13px / `--text-3` / 上间距 12px
- 文案：主「**把今天，排成你想要的样子。**」副「不必遵守日程，只需看清时间。」
- 入场动画：淡入 + 上移 6px，`--dur-slow`，只播一次

### 3.4 四个入口

**不要做成 4 个彩色卡片。** 做成垂直排列的四行文字项，像 Grok 首页的 suggestion 列表：

```
  ⏱  新建任务                                    ⌘N
  ☰  新建 TaskLine                               ⌘T
  ◈  我的成就                                     >
  ✎  任务复盘                                     ●
```

- 每行高 56px，左 20px 图标（16px，`--text-3`），中间 15px 文字（`--text-1`），右快捷键提示（`--text-3`，11px）
- 悬停：整行背景 `--surface-2`，圆角 `--r-md`，图标和右侧提示变 `--text-1`，`--dur-fast`
- 行与行之间间距 4px（靠悬停背景区分，不靠分割线）
- 「任务复盘」右侧的红点：8px 圆，`--danger`，只在有待办复盘时出现（本期先写死显示，P7 接真实逻辑）

### 3.5 左栏（任务池）

在 P2 基础上打磨：
- 顶部：字标 `Auxilia`（15px / 500 / `--text-2`）+ 右侧一个「+」（hover 才显示）
- 搜索框：46px 高，无边框，只有底部 `1px rgba(255,255,255,0.06)`，聚焦时变 `0.14`，transition `--dur-base`
- 任务项高 44px，圆角 `--r-md`，标题单行省略
- 分级视觉：等级 ≤ 3 正常；≥ 5 的标题右侧加一个小圆点，透明度随等级递增（最高 0.5）
- 底部署名区：一行 11px `--text-3`，显示「今日 2h 15m」（本期先占位）

### 3.6 右栏（TaskLine 容器）

本期只做壳：
- 顶部：TL 名称 + 下拉切换箭头（点击展开列表，本期列表只有一项「默认 TaskLine」）+ 右侧「+」新建
- 下方时间轴区域：从 6:00 到 24:00，每小时一条 `1px rgba(255,255,255,0.04)` 横线，左侧 11px `--text-3` 小时标签
- 当前时间那条线用 `--accent` 20% 透明度，最左侧一个 2px 小圆点，**每 60 秒重新定位一次**
- 空状态：时间轴中央一行灰字「把任务拖到这里，它只是个参考，不会自己跑」

> 这句文案很重要——它在产品内部自我解释了 P1 哲学。

### 3.7 响应式与收起

- 窗口 < 980px：右栏自动收起，中栏右侧出现一个窄把手可手动展开
- 左栏支持手动收起（标题栏左侧一个图标切换），收起后宽度 0，用 `transform` 过渡
- 所有收起状态存 `settings` 表，下次启动恢复

## 关键要求

1. **三级灰阶必须拉开差距**：`--text-1 #FAFAFA` / `--text-2 #A1A1A1` / `--text-3 #5C5C5C`。截图灰度检查，三层能一眼分开。
2. 中栏大量留白。宁可空，也不要塞"提示文案""使用技巧"来填空隙。
3. 所有 hover 只改 `background` 和 `color`，不改尺寸（避免抖动）。
4. 布局用 Flex + `min-width:0` 处理溢出，不要用 `calc` 堆魔法数字。
5. 收起/展开用 `transform: translateX()` + `width` 的 GPU 友好组合，实测 60fps。
