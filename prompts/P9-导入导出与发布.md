## 9.1 批量管理（FR-I4）

任务池与 TaskLine 都支持：

- 进入方式：`Ctrl/Cmd + 点击` 多选，或从空白处拖出一个选择框
- 选中后顶部浮出一条**操作条**（不是弹窗），距顶部 12px，胶囊形，`--surface-2` + 极淡描边：
  ```
  已选 5 项   加入 TL ▾   删除   取消
  ```
- 操作条出现时列表整体向下推 8px（`--dur-base`）
- 「加入 TL」→ 下拉选目标 TL + 选小时
- 「删除」→ 行内二次确认
- `Esc` 或「取消」清空选择
- 全选：`Ctrl/Cmd + A`

## 9.2 导出码（FR-I1 ~ FR-I3）

```ts
// src/lib/export.ts
import { deflateRaw, inflateRaw } from 'pako';   // 唯一允许新增的依赖

const MAGIC = 'aux1:';

function encode(payload: object): string {
  const json = JSON.stringify(payload);
  const bytes = deflateRaw(new TextEncoder().encode(json));
  return MAGIC + base64url(bytes);
}
```
- 需要新增依赖 `pako`（约 45KB，可接受），在 P9 开工前先说明并确认
- 导出内容：`{ v: 1, kind: 'tasks' | 'taskline', exportedAt, items }`
  - `tasks` 导出：任务所有字段（不含 id，导入时重新生成）
  - `taskline` 导出：TL 定义 + 其条目（条目里用任务**标题**作为引用，导入时按标题匹配；匹配不到则创建新任务）
- 导出面板：
  ```
  导出 12 个任务
  ┌──────────────────────────┐
  │ aux1:eJx1Vk1v2zAM...    │   ← 等宽字体，10px，可全选
  └──────────────────────────┘
  3,482 字符            [复制]  [保存为文件]
  ```
- 长度 > 8000 时显示黄色提示：「内容较多，建议分批导出或保存为文件」
- 复制成功：按钮文字变「已复制」，1.5s 后复原（不加 toast）

### 导入
- 粘贴码或选文件
- 校验顺序：`aux1:` 前缀 → 解压成功 → `v === 1` → 结构完整
- 任一失败给出**具体**原因：
  - `导入码格式不正确，应以 aux1: 开头`
  - `导入码已损坏，无法解压`
  - `不支持的版本 v2，请升级 Auxilia`
- 重复检测：按 `title + createdAt` 判定
- 冲突处理给三选（**必须让用户选，不许自动决定**）：
  ```
  发现 3 个同名任务
  [ 跳过重复 ]  [ 创建副本 ]  [ 全部覆盖 ]
  ```

## 9.3 首次引导（FR-A1 ~ FR-A3）

**不是教程页。** 是让用户真的完成一次任务。

```
Step 1  ─────────────────────────────────
        欢迎使用 Auxilia
        它不会替你安排时间。
        
        先建一个你现在就想做的事。       [ 开始 ]

Step 2  复用 P4 的新建任务面板，标题预填「试试 Auxilia」，
        时长默认 25 分钟，其余默认。用户可改可删。

Step 3  你希望用哪个键随时叫出它？
        [ Shift + Space ]               ← 点击后进入录制状态，按下组合键即生效
        如果被占用会提示换一个

Step 4  好了。
        开始你的第一个 25 分钟。        [ 现在开始 ]
```
- 4 步在同一容器内推进，顶部一条 4 段进度线（每段 24px，当前段 `--text-1`，其余 `rgba(255,255,255,0.10)`）
- 全程 `--dur-base` 转场
- 完成后写 `settings.onboarded = true`
- 设置页「重新观看引导」可重跑

## 9.4 设置面板

从标题栏右侧齿轮进入，中栏切换为设置视图。分组：

```
快捷键
  唤起主窗口        Shift + Space    [ 修改 ]
  
启动
  开机自动启动       [开关]
  启动后最小化到托盘  [开关]

通知
  系统通知          [开关]
  提示音            [开关]

数据
  数据库位置        %APPDATA%/Auxilia/auxilia.db   [打开所在文件夹]
  导出全部数据       [导出]
  导入数据           [导入]

复盘
  （复用 P7 的设置项）

关于
  版本 1.0.0
  重新观看引导
```

- 改快捷键：点击「修改」→ 该行变录制态，显示「请按下新的组合键…」，按下后校验（必须含至少一个修饰键），冲突时提示
- 所有开关改动**立即生效并落库**，没有「保存」按钮

## 9.5 应用图标（设计师产出）

风格锚点：App Store 的 squircle 轮廓 + Grok 的几何极简。

**主方案**：
- 底板：1024×1024 的 squircle（圆角半径约 225），填充 `#EDEDEA`（暖白，不是纯白）
- 主体：居中的纯黑 `#000000` 字母 **A**，几何化处理：
  - 去掉衬线，用等宽直线
  - A 的横杠缩短到只连接两侧，不突出
  - 整体占画布高度 52%
- 不加投影、不加渐变、不加任何第二元素

**备选方案**（如果主方案在深色任务栏上太跳）：
- 底板 `#0B0B0B` squircle，主体米白 `#F5F4F0` 的 A

产出：
1. `src-tauri/icons/icon.svg`（矢量源文件）
2. 1024×1024 PNG
3. 运行 `pnpm tauri icon src-tauri/icons/icon.png` 自动生成全套尺寸（ico/icns/png）
4. 验证 16×16 下 A 仍然清晰可辨（缩到最小尺寸看，糊了就简化 A 的结构）

## 9.6 性能收尾（FR-J6）

逐项实测并优化到目标：

| 项 | 目标 | 手段 |
|---|---|---|
| 空闲内存 | ≤ 90MB | 主窗口 hide 后卸载渲染树（`<div className="w-0 h-0"/>`），显示时重新挂载 |
| 前台内存 | ≤ 180MB | Bundle 分析，砍掉未用依赖 |
| 冷启动 | ≤ 1.2s | 路由懒加载；首屏只加载 home |
| 空闲 CPU | ~0% | 确认无残留 `setInterval`；后台 tick 500ms 开销可忽略 |

额外：
- `pnpm build` 后检查 `dist/assets` 总体积，JS < 400KB（gzip 后）
- 用 `pnpm why` 检查是否有意外引入的大包
- 全局搜 `setInterval` / `requestAnimationFrame`，确认每个都有对应的清理

## 9.7 打包发布

```bash
pnpm tauri build
```
- 产物：`src-tauri/target/release/bundle/nsis/Auxilia_1.0.0_x64-setup.exe`
- `tauri.conf.json` 填好 `productName: "Auxilia"`、`identifier: "com.auxilia.app"`、`version: "1.0.0"`
- 安装到干净目录，验证：桌面快捷方式、开始菜单项、卸载程序正常
- 卸载后 `%APPDATA%/Auxilia` 保留（用户数据不能被卸载删掉，除非用户主动勾选）
