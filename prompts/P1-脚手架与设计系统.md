# P1 · 脚手架与设计系统

**角色**：桌面工程师（R4）+ 视觉设计师（R2）
**前置**：无（从零开始）
**验收官**：R5

---

## 目标

一个能被 `pnpm tauri dev` 启动的黑色空壳，`Shift+Space` 可以唤起和隐藏，tokens.css 定稿，之后所有代码都建立在这上面。

**完成这个阶段后，不要再动脚手架配置。** 后面的所有问题都应该在业务层解决。

---

## 任务

### 1.1 环境确认

按顺序验证，任一失败就停下报告，不要往下走：

```bash
node -v          # ≥ 20
rustc --version  # 没有就先装：winget install Rustlang.Rustup
cargo --version
```
还需要 **Microsoft C++ Build Tools**（安装时勾选「使用 C++ 的桌面开发」+ Windows SDK）。装完重开终端。

### 1.2 初始化项目

在 `D:\project\auxilia` 下：

```bash
pnpm create tauri-app@latest . --template react-ts --manager pnpm
pnpm add zustand motion date-fns lucide-react
pnpm add -D tailwindcss @tailwindcss/vite
```

Rust 侧依赖（`src-tauri/Cargo.toml`）：
```toml
tauri-plugin-sql = { version = "2", features = ["sqlite"] }
tauri-plugin-global-shortcut = "2"
tauri-plugin-autostart = "2"
tauri-plugin-notification = "2"
tauri-plugin-single-instance = "2"
tokio = { version = "1", features = ["time", "sync"] }
nanoid = "0.4"
serde = { version = "1", features = ["derive"] }
serde_json = "1"
chrono = "0.4"
```

### 1.3 tokens.css（设计师的核心产出）

创建 `src/styles/tokens.css`，把 P0 第 3 章的所有变量落地，并额外补：

```css
:root {
  /* 颜色 · 字体 · 圆角 · 间距 · 动效 —— 全部照 P0 第 3 章 */
  /* 额外补充： */
  --sidebar-w: 260px;
  --rightbar-w: 380px;
  --titlebar-h: 38px;
  --timer-size: 72px;
}
html, body, #root { height: 100%; background: var(--bg); color: var(--text-1); }
body { font-family: var(--font-sans); -webkit-font-smoothing: antialiased; }
* { font-variant-numeric: tabular-nums; }   /* 全局开，避免计时器抖动 */
::selection { background: rgba(255,255,255,0.14); }
/* 自定义滚动条：极细，深灰，hover 才明显 */
::-webkit-scrollbar { width: 6px; }
::-webkit-scrollbar-thumb { background: rgba(255,255,255,0.10); border-radius: 3px; }
::-webkit-scrollbar-thumb:hover { background: rgba(255,255,255,0.18); }
::-webkit-scrollbar-track { background: transparent; }
```

在 `tailwind.css` 里用 `@theme` 把 CSS 变量映射成 Tailwind token，使 `bg-surface-1`、`text-text-2` 这类类名可用。**不要在用的时候写 `bg-[#0A0A0A]`。**

### 1.4 窗口配置

`src-tauri/tauri.conf.json`：
- 主窗口 `width: 1100, height: 720, minWidth: 900, minHeight: 600`
- `decorations: false`、`transparent: false`、`center: true`
- `resizable: true`
- 关闭按钮行为改为 hide（在 `lib.rs` 里拦截 `CloseRequested`）

自绘标题栏 `src/components/layout/TitleBar.tsx`：
- 高 `var(--titlebar-h)`，`data-tauri-drag-region` 支持拖动
- 右侧三个 12px 圆点：关闭 / 最小化 / 最大化（hover 才显示图形，常态就是三个灰点——苹果风）
- 左侧留空，不要放 logo（P0 反模式）

### 1.5 全局快捷键

```rust
// hotkey.rs
// 注册 shift+space，按下时 toggle_main_window
// 注册失败必须 emit("hotkey:failed", reason) 让前端提示，不许静默
```
`toggle_main_window`：
- 可见 → `hide()`
- 隐藏 → `show()` + `set_focus()` + 居中对齐上一次位置

### 1.6 托盘与自启

- 托盘图标 + 菜单：`显示 / 暂停·继续（本期灰置）/ 结束当前任务（本期灰置）/ 退出`
- `tauri-plugin-autostart` 默认启用，启动参数带 `--minimized` → 启动后直接 hide
- 单实例插件：第二次启动时唤起已有窗口，不开新实例

### 1.7 数据库连接

本期只做"能连上、能建表"，不做业务：
- 在 `lib.rs` 里注册 `tauri-plugin-sql`，`migrations` 指向 `migrations/*.sql`
- 先建一张 `settings` 表即可（完整 13 表留给 P2）
- 前端 `src/lib/db.ts` 封装 `getDb()` 单例，验证能读写

### 1.8 一个真实的空状态

中栏放 slogan（示例文案：**"把今天，排成你想要的样子。"**），副标题一行小字，下面四个入口按钮（新建任务 / 新建 TaskLine / 我的成就 / 任务复盘）。按 P0 视觉铁律做，不要卡片不要边框。左右两栏先放占位空容器。

## 关键要求

1. **本项目所有窗口预创建，用 show/hide 切换，不销毁重建**（架构文档第 3 章）。本期先只做 main，但 `lib.rs` 的结构要预留窗口管理模块。
2. 无边框窗口在 Windows 上会丢失系统的拖动/双击最大化，必须用 `data-tauri-drag-region` 补偿，且要把按钮区域排除在拖拽区外。
3. tokens.css 里每个变量都写一行中文注释说明用途。后面设计师和前端都靠它对齐。
4. 不要在这一期引入任何业务代码、路由页面、状态 store。

## 验收标准（R5 逐条实测）

| # | 检查项 | 判定方式 |
|---|---|---|
| 1 | `pnpm tauri dev` 编译通过并启动 | 看到黑底窗口 |
| 2 | 背景是纯 `#000000` | 取色器验证，不是 #0a0a0a |
| 3 | 窗口无系统边框，拖动自定义标题栏能移动窗口 | 手动拖 |
| 4 | `Shift+Space` 在软件失去焦点时仍能唤起/隐藏 | 切到浏览器再按 |
| 5 | 点击关闭按钮 → 窗口隐藏，托盘图标仍在，进程未退出 | 任务管理器确认 |
| 6 | 托盘菜单「显示」能重新打开窗口 | 点击 |
| 7 | 重启电脑后软件自动启动并隐藏到托盘（带 `--minimized`） | 重启验证，或查启动项 |
| 8 | 重复启动 exe 不会再开一个实例，而是唤起已有窗口 | 双击两次 |
| 9 | `tokens.css` 中无硬编码色值散落在组件里 | 全局搜 `#` 和 `rgb(` |
| 10 | 中栏 slogan + 4 个入口显示正常，无分隔线、无卡片阴影 | 目测 |
| 11 | 字体数字为等宽数字（tabular-nums） | 随便放个数字观察对齐 |
| 12 | 滚动条是 6px 细条、深灰、透明轨道 | 造一个超高 div 观察 |
