# Auxilia 技术架构 v1.0

> 配套 `01-产品规格书.md`。本文档给出**怎么实现**，包括可直接执行的 SQL、关键算法和踩坑预案。
> 所有技术选型都是**硬约束**——提示词里会引用本文档，AI 不得擅自换库。

## 1. 技术选型

| 层 | 选型 | 理由 / 约束 |
|---|---|---|
| 桌面壳 | **Tauri 2** | 用系统 WebView2，常驻内存 40-80MB，满足 FR-J6 |
| 前端框架 | **React 19 + TypeScript** | 生态最厚，AI 生成质量最高 |
| 构建 | **Vite 6** | Tauri 官方推荐，冷启动快 |
| 样式 | **Tailwind CSS v4 + CSS 变量** | token 必须走 CSS 变量，禁止散落魔法值 |
| 状态 | **Zustand** | 比 Redux 轻，比 Context 少重渲染 |
| 动画 | **Motion（framer-motion）** | 布局动画和手势成熟 |
| 数据库 | **SQLite** via `tauri-plugin-sql` | 单文件，本地，事务可靠 |
| 日期 | **date-fns** | 按需引入，不要 moment |
| 图标 | **lucide-react** | 线性图标，克制，符合极简 |
| 图表 | **手写 SVG**（热力图/柱图/环图） | 不引 echarts/recharts，省 300KB+ 和内存 |
| 快捷键 | `tauri-plugin-global-shortcut` | 官方 |
| 开机自启 | `tauri-plugin-autostart` | 官方 |
| 通知 | `tauri-plugin-notification` | 官方 |
| 单实例 | `tauri-plugin-single-instance` | 防止开两个实例抢快捷键 |
| 崩溃恢复 | 自定义 `app_state` 表 | 见 5.4 |

**禁止引入**：Ant Design / MUI / Element / echarts / moment / lodash 全量包。

## 3. 进程与窗口模型

```
┌──────────────────────── Rust Core (单进程) ────────────────────────┐
│  · SQLite 连接池                                                   │
│  · Engine：tokio interval(500ms) 后台调度                          │
│      ├─ 检测 countdown 归零 → emit "timer:finished"                │
│      ├─ 检测 scheduled 触发 → emit "scheduled:fire"                │
│      ├─ 每 60s 更新托盘 tooltip                                     │
│      └─ 每 60s 落库 run_segments 快照（崩溃恢复用）                  │
│  · 全局快捷键监听                                                   │
│  · 托盘菜单                                                        │
└────────────────────────────────────────────────────────────────────┘
        │ IPC                          │ IPC                    │ IPC
   ┌────▼─────┐    ┌────────▼────────┐  ┌──▼──────────┐   ┌──────▼──────┐
   │  main    │    │  mini (顶栏浮条) │  │ float (浮窗) │   │ flash (闪屏) │
   │ 1100×720 │    │  96×26 贴顶     │  │ 220×64      │   │ 全屏透明     │
   │ 无边框    │    │ always_on_top  │  │ always_on_top│   │ 120ms 后隐藏 │
   └──────────┘    └────────────────┘  └─────────────┘   └─────────────┘
```

**窗口存活策略**：
- `main`、`mini`、`float`、`flash` 在启动时全部预创建，用 `show/hide` 切换，**不销毁**。销毁重建会有 300ms+ 白屏。
- 关闭主窗口 = `hide()`，同时把渲染树替换为空占位（省内存，见 9.2）。
- 真正退出只走托盘菜单「退出」。

### 5.2 数据坑位
- 所有时间戳统一 **毫秒 int64**，不用 ISO 字符串（排序、跨时区都省事）。
- 所有写操作必须包事务。
- 软删除统一用 `deleted_at IS NOT NULL`，查询一律带 `WHERE deleted_at IS NULL`。
- `level = FLOOR(total_seconds / 6000) + 1`（每 100 分钟一级，FR-G4）。

## 6. 关键算法

### 6.1 计时引擎（最重要，做错全盘皆输）

**铁律：永不累加，永远用时间戳差。** 前端 `setInterval` 只能用来触发重绘，不能用来累计时间。

```rust
// engine.rs
pub struct RunState {
    pub run_id: String,
    pub task_id: String,
    pub mode: DurationMode,
    pub planned_seconds: i64,
    /// Some(t) = 正在跑；None = 暂停中
    pub segment_started_at: Option<i64>,
    /// 已闭合区间的秒数之和
    pub closed_seconds: i64,
    pub paused_seconds: i64,
    pub interruptions: u32,
}

impl RunState {
    pub fn active_seconds(&self, now: i64) -> i64 {
        self.closed_seconds
            + self.segment_started_at.map_or(0, |s| (now - s).max(0) / 1000)
    }
}

// 后台调度：tokio::interval(Duration::from_millis(500))
async fn tick(app: AppHandle) {
    let now = now_ms();
    // 1) 倒计时归零
    if let Some(run) = state.active_run() {
        if run.mode == DurationMode::Countdown && run.active_seconds(now) >= run.planned_seconds {
            finish_countdown(&app, &run);   // emit "timer:finished" → 前端转结束流程
        }
    }
    // 2) scheduled 待触发
    for task in due_scheduled_tasks(now) {
        if state.active_run().is_some() {
            emit(&app, "scheduled:conflict", task);   // FR-E7 弹窗询问
        } else {
            start_task(&app, task.id, /*auto*/ true);
        }
    }
    // 3) 心跳（60s 一次）
    if now % 60_000 < 500 { heartbeat(&app, &now); }
    // 4) 托盘 tooltip（60s 一次，别每秒调，有系统开销）
    if now % 60_000 < 500 { update_tray_tooltip(&app); }
}
```

**前端计时显示**：不订阅 Rust 的每秒推送。前端持有 `{ segmentStartedAt, closedSeconds }`，用一个 `useEffect` + `requestAnimationFrame`（窗口可见时 1s 节流、不可见时暂停）自行计算。窗口隐藏被节流也无所谓——恢复时数值自动正确。

**暂停**：`closed_seconds += (now - segment_started_at)/1000`，闭合 `run_segments`，`segment_started_at = None`。
**继续**：`segment_started_at = Some(now)`，插入新 segment。
**结束**：闭合 segment，写 `task_runs`，更新 `tasks.total_seconds / level / status`，清 `app_state.run_id`。

### 6.2 阻尼滚轮（`lib/physics.ts`）

这是手感的全部。**不要用 CSS scroll-snap**（太硬，没有惯性）。

```ts
export const WHEEL = {
  ITEM_H: 44,
  FRICTION: 0.94,      // 自由滑行衰减
  SPRING_K: 0.16,      // 吸附刚度
  SPRING_D: 0.70,      // 吸附阻尼
  MIN_VEL: 0.4,        // 低于此速度切吸附
  WHEEL_GAIN: 0.32,    // wheel delta → 速度
};

// 每帧执行
function frame(s: { offset: number; velocity: number; target: number | null }) {
  if (Math.abs(s.velocity) > WHEEL.MIN_VEL) {
    s.offset += s.velocity;
    s.velocity *= WHEEL.FRICTION;
  } else {
    if (s.target === null) {
      s.target = Math.round(s.offset / WHEEL.ITEM_H) * WHEEL.ITEM_H;
    }
    s.velocity += (s.target - s.offset) * WHEEL.SPRING_K;
    s.velocity *= WHEEL.SPRING_D;
    s.offset += s.velocity;
    if (Math.abs(s.target - s.offset) < 0.3 && Math.abs(s.velocity) < 0.3) {
      s.offset = s.target; s.velocity = 0; s.target = null;  // 收敛
    }
  }
}
```

渲染（每项）：
```
translateY(offset - index * ITEM_H)
scale   = 1 - min(|d| / (ITEM_H*3), 1) * 0.18
opacity = 1 - min(|d| / (ITEM_H*3.2), 1) * 0.75
```
上下各加 `mask-image: linear-gradient(transparent, #000 30%, #000 70%, transparent)`。

**循环**：小时 0-23、分钟 0-59，越界时对 `index` 取模，`offset` 保持连续（不要跳变，否则会有视觉撕裂）。

**快捷胶囊**（FR-C4）：点击 → `state.target = value * ITEM_H; state.velocity = (target - offset) * 0.12`（给一脚初速度，让弹簧动画明确可见）。

**手感细节**（验收时逐条感受）：
1. 快速甩动可以一次滚 10+ 格，然后**平滑减速**停下，不是急刹。
2. 松手后**一定会**对齐到整数格，不会停在 12.7 分钟。
3. 轻拨一格，滚轮只走一格，且停下时有一个极轻的回弹（`scale` 微过冲）。
4. 拖拽（按下鼠标上下移动）与非拖拽滚轮共用同一套物理，只是初始速度来源不同。
5. 滚动时不触发页面滚动（`e.preventDefault()`），且不触发文本选中。

## 7. 全局快捷键（FR-J2）

```rust
app.global_shortcut().on_shortcut("shift+space", |app, _, event| {
    if event.state == ShortcutState::Pressed {
        toggle_main_window(app);   // 可见→隐藏（并清空渲染树）；隐藏→居中+聚焦搜索框
    }
})?;
```
- 注册失败（被输入法/其他软件占用）必须 `emit("hotkey:failed")` 并引导去设置改键，**不允许静默失效**（E-6）。
- 窗口隐藏超过 5 分钟再唤起时，主窗口根节点先渲染骨架，再异步 hydrate（避免 500ms 卡顿感）。

## 8. 状态机

```
                 ┌──────────────── 完成 ────────────────┐
                 │                                      ▼
  idle ──开始──► running ──暂停──► paused ──继续──► running ──结束──► finishing
                 │  ▲                                    │              │
                 └──┴────────────────────────────────────┘              │
                 │                                                      ▼
                 └──中止──────────────────────────────────────────► aborted
```

`finishing` 是前端路由态（`/finish/:runId`），不是数据库 status。数据库里 `running/paused` 是瞬时态，进程重启时必须被 `app_state` 校正。

## 9. 性能预算与实现手段

### 9.1 目标（FR-J6）
| 指标 | 目标 | 红线 |
|---|---|---|
| 空闲常驻内存 | ≤ 90MB | 120MB |
| 前台运行内存 | ≤ 180MB | 250MB |
| 冷启动可交互 | ≤ 1.2s | 1.5s |
| 空闲 CPU | ~0% | 1% |

### 9.2 具体手段
1. **隐藏即卸载**：主窗口 `hide` 后，把 `<App/>` 换成 `<div class="w-0 h-0"/>`，保留进程不保留渲染树。再显示时重新挂载（从 SQLite 读，冷读 < 30ms）。
2. **图表不引库**：热力图 = 365 个 `<rect>`；柱图/环图 = 纯 SVG path。省 ~350KB JS 和一份运行时。
3. **列表虚拟化**：任务池 > 80 条时启用窗口化渲染。
4. **不用 CSS-in-JS**：Tailwind 编译期产物，运行时零开销。
5. **Rust 侧不做重计算**：统计聚合走 SQL（`GROUP BY date(started_at/1000,'unixepoch','localtime')`），不拉全表到内存。
6. **不订阅每秒 IPC**：前端自算，只订阅阈值事件。
7. **图标按需引入**：`lucide-react` 具名导入，确认 tree-shaking 生效。

## 11. 已知风险与预案

| 风险 | 概率 | 预案 |
|---|---|---|
| Rust 环境装不上 / 编译失败 | 中 | 先用 `pnpm tauri dev` 跑通空壳，再逐模块加功能；P1 单独验收环境 |
| 全屏透明窗口在部分 GPU 黑屏 | 中 | 降级为低透明度不透明窗口 |
| `Shift+Space` 被输入法占用 | 高 | 默认改 `Alt+Space`? 不——Windows 上 `Alt+Space` 是系统菜单。备选 `Ctrl+Shift+Space` |
| WebView2 隐藏窗口定时器节流 | 高 | 已用「时间戳差」规避，**不要改回累加** |
| 无边框窗口拖动/双击最大化失效 | 中 | 用 `data-tauri-drag-region`，自绘标题栏但把控制区让出 |
| SQLite 并发写锁 | 低 | WAL 模式 + 单写连接 |
